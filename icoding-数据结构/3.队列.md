# 队列 

## 循环链表表示队列

假设以带头结点的循环链表表示队列，并且只设一个指针指向队尾元素结点（注意不设头指针），请完成下列任务：


1: 队列初始化，成功返回真，否则返回假： bool init_queue(LinkQueue *LQ);

2: 入队列，成功返回真，否则返回假： bool enter_queue(LinkQueue *LQ, ElemType x);

3: 出队列，成功返回真，且*x为出队的值，否则返回假 bool leave_queue(LinkQueue *LQ, ElemType *x);

相关定义如下：
```c
typedef struct _QueueNode {
    ElemType data;          // 数据域
    struct _QueueNode *next;      // 指针域
}LinkQueueNode, *LinkQueue;
```
### 答案
```c
bool init_queue(LinkQueue *LQ)//传入的是一个二级指针
{
	(*LQ) = (LinkQueue)malloc(sizeof(LinkQueueNode));//malloc前面表示的是返回的地址，后面是大小，前面如果不加*号的话不能修改外部值
	if((*LQ) == NULL)    //我发现很多分配内存的地方都要进行这样一个检验，有的题目需要有的不需要
	{                    //就当作一个习惯吧
	    return 0;
	}
	(*LQ)->next = (*LQ); //自己指向自己，才是一个循环队列
	return 1;
}

bool enter_queue(LinkQueue *LQ, ElemType x)//队尾进入
{
    LinkQueueNode *s =(LinkQueue)malloc(sizeof(LinkQueueNode));//给元素x分配一个节点
    if(s == NULL)
    {
        return 0;
    }
    s->next =(*LQ)->next;
    s->data =x;
    (*LQ)->next=s;
    (*LQ)=(*LQ)->next;//依旧是尾结点
    return 1;
}

bool leave_queue(LinkQueue *LQ, ElemType *x)
{
    if((*LQ)->next==(*LQ))//判断是不是空队列
    {
        return 0;
    }
    LinkQueueNode *p =(*LQ)->next->next;//队尾结点，虚拟头结点，队头元素
    *x=p->data;
    (*LQ)->next->next =p->next;    //头结点指向下一个结点
    if(p == *LQ) {         //针对只剩下一个元素的情况，即p和尾结点重合
        *LQ = (*LQ)->next;
    }
    free(p);
    return 1;
}
```
