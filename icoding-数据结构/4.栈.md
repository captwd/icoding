# 栈 
## 后缀表达式计算

请使用已定义好的栈完成后缀表达式计算：
(1)如果是操作数，直接入栈
(2)如果是操作符op，连续出栈两次，得到操作数x 和 y,计算 x op y，并将结果入栈。
```
后缀表达式示例如下：
9  3  1  -  3  *  +  10  2  /  +
13  445  +  51  /  6  -
操作数、操作符之间由空格隔开，操作符有 +，-，*, /, %共 5 种符号，所有操作数都为整型。

栈的定义如下：
#define Stack_Size 50
typedef struct{
    ElemType elem[Stack_Size];
    int top;
}Stack;

bool push(Stack* S, ElemType x);
bool pop(Stack* S, ElemType *x);
void init_stack(Stack *S);

其中，栈初始化的实现为：
void init_stack(Stack *S){
    S->top = -1;
}
需要完成的函数定义为：int compute_reverse_polish_notation(char *str);
```
函数接收一个字符指针，该指针指向一个字符串形式的后缀表达式，函数返回该表达式的计算结果

### 答案
```
int compute_reverse_polish_notation(char *str) { 
    Stack S; 
    init_stack(&S);    //这个地方建议不要直接定义 Stack *s；和内存分配有点关系
    int x, y, a; 
    
    while(*str != '\0') { 
        // 1. 处理数字（可能是多位数）
        if(*str >= '0' && *str <= '9') { 
            int num = 0; 
            // 循环读取完整的数字
            while(*str >= '0' && *str <= '9') { 
                num = num * 10 + (*str - '0'); 
                str++; // 指针后移
            } 
            push(&S, num); // 循环结束后，压入完整的数字
            continue;      // 跳过本次循环末尾的 str++，因为上面已经移动过指针了
        } 
        
        // 2. 处理运算符（排除空格）
        if(*str != ' ') { 
            pop(&S, &y); 
            pop(&S, &x); 
            
            switch(*str) { 
                case '+': push(&S, x + y); break; 
                case '-': push(&S, x - y); break; 
                case '*': push(&S, x * y); break; 
                case '/': 
                    if(y != 0) push(&S, x / y);   //对0处理一下，不处理应该也行吧，看题目，主要是没说明
                    else push(&S, 0); 
                    break; 
                case '%': 
                    if(y != 0) push(&S, x % y); 
                    else push(&S, 0); 
                    break; 
            } 
        } 
        str++; // 处理完运算符或空格后，指针后移
    } 
    pop(&S, &a); 
    return a; 
}
```

### 思路
这个地方，主要是那个多位数的地方，以及一个空格的处理，运算符比较难以处理，直接用switch枚举了
