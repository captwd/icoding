# 顺序表 

## 1.删除指定范围

设计一个高效的算法，从顺序表L中删除所有值介于x和y之间(包括x和y)的所有元素（假设y>=x），要求时间复杂度为O(n)，空间复杂度为O(1)。

函数原型如下：
```c
void del_x2y(SeqList *L, ElemType x, ElemType y);
```

相关定义如下：
```c
struct_seqlist{
    ElemType elem[MAXSIZE];
    int last;
};
typedef struct _seqlist SeqList;
```
### 参考答案
```c
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

void del_x2y(SeqList *L, ElemType x, ElemType y) {
    int k=0;
    for(int i=0;i<=L->last;i++)
    {
        if(L->elem[i]<x || L->elem[i]>y)
        {
            L->elem[k]=L->elem[i];
            k++;
        }
    }
    L->last = k-1;
}
```
### 思路

一个很经典的***快慢指针***问题，类似于再创建一个数组，把符合要求的元素装入第二个数组中。

如果传入的不是一个指针，然后输出的不是一个空值而是数组的话，再创建一个数组也比较方便。

最后的last截断到需要的数字位置，就等于把后面的数字抛弃了，***后续数据结构很多地方都会用到这种思想。***

我刚开始还想着比大小交换顺序，但是最后会遇到多个不满足要求的元素连在一起，应该是行不通的。

***拓展***
头尾双指针法

1.设置两个指针，i 从前往后找，j 从后往前找。

2.只要 i 遇到了在 [x, y] 范围内的“坏元素”，我们就把它和 j 指向的“好元素”进行位置交换。

3.交换完之后，j 往前缩一步。

4.直到 i 和 j 相遇，整个数组就被我们分为两半：前面全是好元素，后面全是坏元素。

5。处理一下last



## 2.删除重复

编写算法，在一非递减的顺序表L中，删除所有值相等的多余元素。要求时间复杂度为O(n)，空间复杂度为O(1)。

函数原型如下：
```c
void del_dupnum(SeqList *L)
```
相关定义如下：
```c
struct _seqlist{
    ElemType elem[MAXSIZE];
    int last;
};
typedef struct _seqlist SeqList;
```

### 参考答案
```c
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

void del_dupnum(SeqList *L)  {
    int k=0;
    for(int i=1;i<=L->last;i++)
    {
        if(L->elem[i]==L->elem[i-1])
        {
            continue;
        }
        L->elem[k]=L->elem[i-1];
        k++;
    }
    L->elem[k]=L->elem[L->last];
    L->last = k;
}
```
### 思路
和上一题差不多吧，双指针

## 3.数据调整

已知顺序表L中的数据元素类型为int。设计算法将其调整为左右两部分，左边的元素（即排在前面的）均为奇数，右边所有元素（即排在后面的）均为偶数，并要求算法的时间复杂度为O(n),空间复杂度为O（1）。

函数原型如下：
```c
void odd_even(SeqList *L);
```
相关定义如下：
```c
struct _seqlist{
    ElemType elem[MAXSIZE];
    int last;
};
typedef struct _seqlist SeqList;
```

### 参考答案
```c
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

void odd_even(SeqList *L) {
    int k=0;
    int temp;
    for(int i=0;i<=L->last;i++)
    {
        if(L->elem[i]%2!=0)
        {
            if(i!=k) //避免在i一个偶数都没有碰到的情况下，自己和自己交换
            {
                temp=L->elem[k];
                L->elem[k]=L->elem[i];
                L->elem[i]=temp;
            }
            k++;
        }
    }
}
```
### 思路
快慢指针，如果i碰到的数是奇数，那么就和k交换（此时i应该已经碰到过至少一个偶数，之后k永远都在偶数上，没碰到前i和k始终同步）

最后实现i一碰到奇数就换到奇数列末尾，然后把偶数列第一个换到偶数列末尾


***拓展***
头尾双指针
```c
void odd_even_two_way(SeqList *L) {
    int left = 0;             // 左指针：从头开始
    int right = L->last;      // 右指针：从尾巴开始
    int temp;

    while (left < right) {
        // 左指针一直往右走，直到遇到一个偶数停下
        while (left < right && L->elem[left] % 2 != 0) {
            left++;
        }
        // 右指针一直往左走，直到遇到一个奇数停下
        while (left < right && L->elem[right] % 2 == 0) {
            right--;
        }
        // 左边有个不该待在左边的偶数，右边有个不该待在右边的奇数，交换
        if (left < right) {
            temp = L->elem[left];
            L->elem[left] = L->elem[right];
            L->elem[right] = temp;
        }
    }
}
```
