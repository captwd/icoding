# 链表

## 1.删除范围内结点

已知线性表中的元素（整数）以值递增有序排列，并以单链表作存储结构。试写一高效算法，删除表中所有大于mink且小于maxk的元素（若表中存在这样的元素），分析你的算法的时间复杂度。
```c
链表结点定义如下：
struct _lnklist{
    ElemType data;
    struct _lnklist *next;
};
typedef struct _lnklist Node;
typedef struct _lnklist *LinkList;
函数原型如下：
void lnk_del_x2y(LinkList L, ElemType mink, ElemType maxk)

其中L指向链表的头结点。
```
### 答案

```
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

void lnk_del_x2y(LinkList L, ElemType mink, ElemType maxk) {
    LinkList p=L;  //还是从头节点开始好一点，逻辑判断比较容易
    while(p->next && p->next->data<=mink)
    {
        p=p->next;
    }
    LinkList q=p->next;
    while(q && q->data<maxk)
    {
        LinkList temp=q;
        q=q->next;
        free(temp);
    }
    p->next=q;
}
```
### 思路
因为题目说的是有序排列，那就比较简单了，只需要找到两个边界点就行，
然后把链子连过去，跨过这一段区域

但是很多时候会要求释放内存，所以要把区域内经过的节点都free掉

这里我比较感兴趣的是最开始的两次宏定义，一次定义为***Node***，代表是一个节点，***但往往也要变成指针的形式来使用***，比如Node *p
然后另一个定义是 ****LinkList***，代表LinkList是一个指针，在题目里往往就是***传入的头指针***，后续再定义节点指针的话，类型用Node *或者LinkList都可以

***拓展***

无序排列的情况下该怎么删

快慢指针，用一个前驱节点保证每次都能定位住p后面的一个节点
```c
void lnk_del_x2y_unsorted(LinkList L, ElemType mink, ElemType maxk) {
    Node *pre = L;          // pre 永远指向 p 的前驱节点
    Node *p = L->next;      // p 是当前正在检查的节点

    while (p != NULL) {     // 单循环：从头到尾遍历一遍
        // 如果当前节点的值在范围内，需要删除
        if (p->data >= mink && p->data <= maxk) { 
            pre->next = p->next; // 1. 让 pre 绕过 p，拉住 p 的下一个节点
            free(p);             // 2. 释放 p 的内存
            p = pre->next;       // 3. p 移动到下一个节点（注意 pre 此时不动！）
        } 
        // 如果不在范围内，不需要删除，两人正常携手往前走一步
        else {
            pre = p;
            p = p->next;
        }
    }
}
```

## 2.倒数查找
已知一个带有表头结点的单链表, 假设链表只给出了头指针L。在不改变链表的前提下，请设计一个尽可能高效的算法，查找链表中倒数第k个位置上的结点（k为正整数）。
函数原型为：
```c
int lnk_search(LinkList L, int k, ElemType* p_ele)
```
若查找成功，函数通过指针参数 p_ele 返回该结点 data 域的值，此时函数返回 1；否则，函数返回 0。相关定义如下：
```c
struct _lnklist{
    ElemType data;
    struct _lnklist *next;
};

typedef struct _lnklist Node;
typedef struct _lnklist *LinkList;
```

### 答案
```c
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

int lnk_search(LinkList L, int k, ElemType* p_ele) {
    Node *p = L;   
    int i=1;
    while(p->next!=NULL)
    {
        p=p->next;
        i++;
    }
    for(int j=1;j<=i-k;j++)
    {
        L=L->next;    //这里我没进行克隆，一般还是克隆一下比较好，不要在原链表上操作
    }
    if(k<=i)
    {
        *p_ele = L->data;
        return 1;
    }
    else{
        return 0;
    }
}
```
### 思路
这个思路很平常啊，就是先去遍历完整个链表，得到链表长度，然后再去算倒数第k个

***拓展***

最最经典的快慢指针

```c
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

int lnk_search(LinkList L, int k, ElemType* p_ele) {
    LinkList fast =L;
    LinkList slow =L;
    for(int i=0;i<k;i++)  //快指针先走k步
    {
        if(fast==NULL)
        {
            return 0;   //如果没走完k步就为空了，说明链表太短了
        }
        fast=fast->next;  
    }
    while(fast!=NULL)    //走完k步后一起走
    {
        fast=fast->next;
        slow=slow->next;   
    }
    *p_ele=slow->data;
    return 1;
}
```

## 合并

设线性表A=(a1, a2,…,am)，B=(b1, b2,…,bn)，试写一个按下列规则合并A、B为线性表C的算法，使得：
C= (a1, b1,…,am, bm, bm+1, …,bn) 当m≤n时；
或者
C= (a1, b1,…,an, bn, an+1, …,am) 当m>n时。
线性表A、B、C均以单链表作为存储结构，且C表利用A表和B表中的结点空间构成。注意：单链表的长度值m和n均未显式存储。
函数的原型如下：
```c
void lnk_merge(LinkList A, LinkList B, LinkList C)
```
即将A和B合并为C，其中 C 已经被初始化为空单链表
相关定义如下：
```c
struct _lnklist{
    ElemType data;
    struct _lnklist *next;
};

typedef struct _lnklist Node;
typedef struct _lnklist *LinkList;
```

## 答案
```c
#include <stdio.h>
#include <stdlib.h>
#include "list.h" // 请不要删除，否则检查不通过

void lnk_merge(LinkList A, LinkList B, LinkList C) {
    Node *a=A->next;
    Node *b=B->next;
    Node *c=C;
    while(a!=NULL && b!=NULL)
    {
        c->next=a;   //把a挂到c的后面
        c=c->next;   //c往后移一位
        a=a->next;
        
        c->next=b;   //把b再挂到c的后面
        c=c->next;
        b=b->next;
    }
    if(b==NULL)      //b如果空了那后面都挂a的一长串
    {                //之所以没有写a==NULL的情况，是因为最后停下来就是以b结尾的，当然写了会更清楚
        c->next=a;
    }
}
```
## 思路
思路的话，就是a，b交替接到c的后面吧，第一次做的时候题目没看清楚，以为是把b接到a后面或者把a接到b后面，笑哭
